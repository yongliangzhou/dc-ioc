第1章 IDC暖通冷源监控系统设计原则

1.1 设计原则
依据"先进、实用、稳定、可靠"的总原则，对云数据中心弱电控制系统的软硬件系统进行科学合理的设计。设计兼顾人机并重、舒适易用、节能高效。人工智能及智能机器人参与实现足不出户的运维保障。自主可控的白盒化致力于为数据中心弱电控制系统实现安全可靠、高效节能、自主可扩展。

1.2 冷源系统组成
一台变频制冷机组、一台板式换热器、一台冷却塔(风机变频)、一台变频冷却水泵、一台变频冷冻水泵、冷冻水二次泵、电动阀门、各类传感器、加药旁流水处理设备。制冷单元和冷冻水二次泵(N+1)实现高可用。冷冻水供/回温度设定为18/24℃，板换换热温差约1.5℃，冷却塔选型温差约5.5℃。


第2章 IDC暖通冷源监控系统控制逻辑

2.1 冷源开关机控制逻辑
冷机的开关机涉及整套系统如阀门、冷冻水泵、冷却水泵、冷却塔、冷水机组的共同参与。关机是开机的逆过程。开机顺序:
(1)开启冷冻侧电动开关阀
(2)开启板换冷却侧旁通阀、关闭板换冷却侧出口阀门
(3)冷机冷却侧入口和旁通阀根据冷机冷凝器压差自由调节，阀门动作平滑，冷凝压差稳定
(4)开启冷却塔入口阀门，关闭旁通阀
(5)待收到冷冻侧电动开关阀全开反馈后，即刻开启冷冻一次泵并变频调节
(6)待收到板换冷却侧全旁通阀全开反馈后，即刻开启冷却泵并变频调节
(7)冷却塔开启并变频调节
(8)5S延时后冷机开启，将机组运行参数上传到BAS系统

关机顺序: 关闭冷机 -> 待冷冻水供水温度等于回水温度时延时10S关闭冷冻泵 -> 待冷却水出水温度等于回水温度时延时10S关闭冷却泵 -> 待冷却水出水温度等于回水温度时延时10S关闭冷却塔 -> 待收到冷冻泵和冷却泵关闭信号后复位各个阀门

2.2 冷源加减机控制逻辑
加机条件(满足任一):
(1)末端实时负荷大于正在运行冷机额定制冷量的80%，延时15分钟
(2)二次侧总流量大于一次侧实际流量50m³/h，延时5分钟
(3)正在运行的制冷机FLA大于80%，延时15分钟
(4)正在运行的制冷机FLA大于100%且冷冻水出水温度大于设定温度+0.5℃，延时15分钟

减机条件(满足任一):
(1)两台冷机实时FLA之和小于80%，蓄冷罐出水温度≤18.5℃，二次侧总流量小于一次侧额定流量45%，延时10分钟
(2)末端实时负荷小于正在运行冷机额定制冷量的40%，蓄冷罐出水温度≤18.5℃，二次侧总流量小于一次侧额定流量45%，延时10分钟

2.3 冷源运行模式切换逻辑
三种运行模式: 制冷模式、预冷模式、自然冷却模式

制冷模式 -> 预冷模式(三个条件同时满足，持续超过15分钟):
冷却水回水温度≤22.5℃，冷却水回水温度低于冷冻水回水温度1.5℃，制冷模式运行正常(无故障，冷冻水出水温度<19.3℃)。室外条件: 11℃≤室外湿球温度≤17℃。切换后设定冷却塔出水温度为室外湿球温度+5.5℃(最低不低于18℃)，设定板换冷冻水出水温度为19.5℃。

预冷模式 -> 自然冷却模式(两个条件同时满足，持续超过30分钟):
预冷模式状态正常，冷却泵频率降到最低值且冷机冷冻水进水温度<19.5℃。室外条件: 室外湿球温度<11℃。切换后设定板换冷冻水出水温度为18℃，冷却塔出水温度为室外湿球温度+5.5℃(最低不低于5℃)。

自然冷却模式 -> 预冷模式回退条件:
板换冷冻水出水温度高于18.5℃且冷却泵频率为50Hz，持续超过15分钟。

预冷模式 -> 制冷模式回退条件:
冷却水回水温度高于22.5℃且冷却塔风机频率为50Hz，板换冷冻水进出口温差小于0.5℃，持续超过15分钟。

2.4 蓄冷罐充放冷控制逻辑
蓄冷罐沿垂直方向每隔0.5m安装1个温度传感器(每个蓄冷罐安装两套一用一备)，监视温跃层变化以测定可用冷冻水量。主管路上安装双向流量计判断充冷或放冷模式。

微充冷模式: 当一次侧流量大于二次侧流量时，过量冷冻水(50m³/h可调)充入蓄冷罐。为保证蓄冷罐一直处于"充满"状态，需确保一次泵流量时刻大于二次泵流量。

放冷模式: 只有两套制冷单元同时故障或制冷系统无电力供应时才触发。

超级充冷模式: 罐内可用冷冻水降低至距底部约1/3高度处进入超级充冷。GC向所有或部分UC发出启动超级充冷的命令。当距离蓄冷罐顶约10%处温度变化为设计回水温度时说明蓄冷罐已充满，系统自动退出。

蓄冷罐隔离: 系统正常运行时蓄冷罐供回水管上V3和V4常开，旁通管上V1和V2常闭。故障高低液位报警5分钟后未解除或手动隔离时，先开启V1和V2，当至少一个旁通阀开启成功后再关闭V3和V4。

2.5 冷源启动前检测项目
检查机组的主线路及接地线是否安装完好;检查三相电源是否连接正确;检查电源电压指示是否在额定值容许范围内;检查油位是否超过低位视镜，油温是否正常;检查导叶是否在正常位置，控制位是否在自动上;检查冷冻水温度设定值是否为正常值;检查主电机电流限制设定值是否在100%位置;控制屏的各种显示是否正常;检查机组及系统各处是否有渗漏;查看用户菜单历史故障记录;检查冷却塔池是否漏水、水位是否正常;检查冷却塔风机转向是否正确;检查水泵盘根处是否漏水，各阀门是否正常开启。


第3章 IDC暖通冷源监控系统故障处理

3.1 制冷单元故障切换分类
故障锁定条件与处理:
(1)水泵/冷却塔/冷机启停mismatch -> 锁定，报警、切换、限制制冷模式切换，需人工复位
(2)水泵/冷却塔变频mismatch -> 锁定，报警、切换、限制制冷模式切换，需人工复位
(3)电动阀开关/调节mismatch -> 锁定，报警、切换、限制制冷模式切换，需人工复位
(4)制冷单元IO子站通讯故障 -> 锁定，报警、切换、限制制冷模式切换，需人工复位
(5)水泵/冷却塔/冷机硬接线故障 -> 不允许启动，报警、不切换、限制制冷模式切换，需人工复位
(6)水泵/冷却塔MCC柜处于"就地"状态 -> 不允许启动，报警、不切换、限制制冷模式切换
(7)水泵/冷却塔MCC柜断电 -> 不允许启动，报警、不切换、限制制冷模式切换
(8)电动阀阀控柜处于"就地"状态 -> 不允许启动，报警、不切换、限制制冷模式切换
(9)水泵/冷却塔/冷机处于"手动"状态 -> 只报警、不切换、不限制
(10)冷冻水出水温度过高 -> 只报警、不切换、不限制
(11)所有传感器超出阈值上下限范围 -> 只报警、不切换、不限制

3.2 控制系统测试要点
制冷模式切换预冷模式测试: 冷却泵频率降到最低值且冷机冷冻水进水温度<19.5℃
预冷模式切换自然冷却模式测试: 冷却泵频率降到最低值且冷机冷冻水进水温度<19.5℃
自然冷却模式切换预冷模式测试: 板换冷冻水出水温度高于18.5℃且冷却泵频率为50Hz
预冷模式切换制冷模式测试: 冷却水回水温度高于22.5℃且冷却塔风机频率为50Hz


第4章 IDC暖通末端监控系统

4.1 末端监控系统介绍
通过采用分布式的采集控制系统，对包间精密空调、定位式漏水检测、包间平均温湿度、热通道温湿度、冷通道温湿度、房间内外压差、精密空调送回风温度、供回水水温及空调的控制点位、整定值等接入到对应的运维监控平台，在保障向IT包间提供持续稳定的环境条件下尽量降低空调系统能耗。

4.2 水冷精密空调系统架构
水冷型空调的制冷系统由配套冷机的冷冻水、制冷管道、蒸发器及电动阀组成; 风道系统由风机、风路、空气过滤器、出风口、回风口等组成; 水系统由加湿水和排水系统组成。

4.3 末端包间控制
包间内冷冻水型机房精密空调无电加热和加湿器。供回水干管采用环行布置，各机组间设置阀门，单点故障维修不影响系统运行。主环路供回水立管设有备用管路。采用下送风上回风气流方式，封闭热通道。恒湿一体机: 相对湿度低于30%时开启加湿模式，高于65%时开启除湿模式。新风处理系统采用变频控制，以包间与走廊压差调节风机变频，保证机房维持正压(5-10Pa)。

4.4 末端温度控制逻辑
包间温度变化控制末端控制阀门开度，阀门开度增加引起供回水最不利环路压差变化，二次泵通过变频实现供回水压差稳定，维持冷冻水末端压差设定值0.1MPa(可调)。当二次泵频率等于50Hz延时5min增开一台二次泵; 当两台二次泵频率都低于35Hz延时5min关闭一台二次泵。所有运行的二次泵频率应保持一致，运行数量不低于1台。蓄冷罐故障隔离后二次泵保持工频50Hz运行。

4.5 末端主要组成部件
精密空调、智能控制系统、EC风机、水量调节阀、网络通讯模块、空调盘管。

4.6 末端控制系统测试
末端温度控制测试: 包间温度升高引起需求量增大，系统自动调整阀门开度和泵频率
末端湿度控制测试: 包间空气湿度过高或过低，恒湿一体机自动工作
空气流速控制测试: 包间需求温度升高引起空气流速增大，系统自动调整风机频率
末端压差控制测试: 温度变化引起供回水环路压差变化，通过二次泵变频实现稳定

4.7 精密空调故障处理
滤网压差故障: 检查过滤网是否太脏需更换; 滤网压差软管开口太小(斜着剪增大进气口)、弯折、堵住; 滤网压差调节过大; 空调风机转速过低; 信号线松动需紧固线路

电源变换器故障:
- 无输出保险管正常: 开关电源未工作或进入保护状态，检测引入电源是否有电
- 保险烧或炸: 二极管及开关部位抗干扰电路问题，热敏电阻和电源控制芯片烧坏，更换电源模块
- 有输出电压但电压不稳定: 输入电压过高或过低，取样电阻、误差取样、电源控制器回路中任一处问题都可能导致电压升高，更换电源变换模块
- 开关电源负载有短路: 断开开关电源电路负载逐一检测电源侧还是负载侧，锁定具体短路点
- 电源模块发热严重: 负载过流、负载太小、环境温度过高或散热不良，更换模块，降低温度


第5章 IDC电力监控系统

5.1 电力监控系统范围
电力监控系统包括: 10kV中压配电系统、低压配电系统、变压器、直流电源装置、自备应急柴油发电机组等。控制系统包含电保护器、智能开关、智能仪表、智能型测量控制模块、RTU、PLC、各种单元控制器等，采用标准接口(RS-485、RS-232、RS-422等)、开放的现场总线接入通讯服务器。实现无人或少人职守，含保护、测量、控制、报警、远传、储存、调配等功能。

5.2 10KV备自投系统组成
高压隔离柜、高压断路器柜、高压计量柜、高压电压电流互感器柜、高压连络柜、母联柜、馈线柜。系统通过双环双星型实现高可用。根据应用场景实现: 两路市电并用、市电柴发并用、柴发UPS并用。

5.3 10KV备自投控制逻辑
市电电源之间切换: 当两路市电中任意一路进线前PT市电且开关无保护动作，市电进线开关仍闭合，检测另一路进线前PT有压，延时3S断开1路市电，延时2S断开市电母联上的馈电开关。延时2S闭合母联开关。按2S步距分步闭合失电母线上的馈出开关。当失电市电恢复供电后，手动断开母联恢复独立两路市电供电。自动恢复时进线前PT检测到有压延时10分钟，先断开母联开关，延时2S断开失电段母线馈出开关，延时2S再合进线开关，按2S步距分步闭合馈出开关。

市电和备用电源切换: 两路市电PT均失电且开关无保护分闸时，延时5S断开市电进线开关和母联开关，延时2S断开本段母线上馈电开关，发出启动信号至发电机组并机控制系统。并机控制系统接收启动信号后所有发电机组启动并在应急母线上完成并机。检测到柴发电源进线开关前PT带电且市电无压后延时2S闭合备用电源进线开关，按2S间隔步序闭合变压器馈线开关。市电恢复后，进线前PT检测到有压延时10分钟先跳开油机进线开关再合市电进线开关分步合馈线开关。

闭锁要求: 只有两路市电开关和母联开关均断开才能闭合发电机进线开关(两锁三钥匙)。

5.4 10KV故障切换逻辑
切换过程中控制设备、被控制设备发生故障时应报警并转为手动操作。两路市电进线、两端柴发进线、母联开关因保护分闸动作失败时自动逻辑终止，需运维人员现场排查。如本段母线上某馈线开关处于分闸状态，分步合闸过程不向该开关发出合闸命令。备自投控制器作为Modbus TCP服务端，通讯采用以太网RJ45网口(只监不控)。备自投机柜需提供交流220V双路UPS电源供电。

5.5 0.4KV备自投系统组成
低压联络柜、低压隔离柜、低压开关柜、低压断路器柜、低压补偿柜、不间断电源柜(UPS)。0.4KV开关柜系统主要有进线柜、隔离柜、电容补偿柜、出线柜、联络柜、UPS柜、馈线柜组成。

5.6 0.4KV备自投控制逻辑
倒闸送停电逻辑: 送电时先电源侧后负荷侧，先合电源侧开关设备后合负荷侧开关设备; 停电时先负荷侧后电源侧，先拉负荷侧开关设备后拉电源侧开关设备。

储能停送电逻辑: 市电输入正常时UPS将市电稳压后供应给负载并同时向机内电池充电; 市电中断时UPS立即将电池直流电能通过逆变器转换为220V交流电继续供应负载。


第6章 IDC柴油发电机并机系统

6.1 柴油发电机维护及操作
具备柴油发电机并机PLC系统的控制模块、并联加减机、柴油发电机启动逻辑、故障切换逻辑、并联控制线、并联合闸开关、接地电阻、开关柜的日常操作及维护能力。

6.2 柴发并机逻辑
两路市电PT均失电延时5S发送发电机启动信号。并机控制系统接收到任意一个启动信号后所有发电机组启动并在应急母线上完成并机。并机控制系统闭合并机母线上的馈电开关向市电母线输出电能。如发出启动信号后超过设定时间(3~10分钟可调)柴发进线前PT检测为无压信号，判断为并机系统故障，中止备自投控制逻辑。单路市电恢复后油机转市电无延时发出本组油机停机信号。当油机收到同组2个停机信号对应油机并机馈出开关分闸。当油机收到2组4个停机信号油机进入停机冷却状态。


第7章 IDC燃油监控系统

7.1 燃油自控维护及操作

第9章 IDC各功能间空调控制

9.1 变电所/冷冻站/配电间/设备间
采用冷冻水型机房精密空调，内无电加热和加湿器。采用上送风侧回风气流方式。恒湿一体机进行加湿除湿，机组放置在空调区或房间内。设备间空调设备为N用1备。

9.2 运营商机房
设计冷冻水型机房精密空调，内无电加热和加湿器。采用上送风侧回风气流方式，送风经风管直吹送至房间。空调设备为N+1备用。预留移动式除湿机插座便于极端天气使用。

9.3 电池室
设计风冷直膨型机房专用精密空调系统，内无电加热和加湿器。采用风管上送风侧回风气流方式。空调设备为N用1备。

9.4 设计原则
以上系统均实现N+1保证高可靠。


第10章 IDC暖通氟泵精密空调

10.1 系统架构
数据中心末端空调按冷却方式分为直膨型氟空调和水冷型空调，包含五个系统: 制冷系统、风道系统、水系统、电气系统、控制系统。氟泵型空调制冷系统由压缩机、冷凝器、膨胀阀、蒸发器、电磁阀、干燥过滤器、储液罐及制冷管道组成。风道系统由风机、风路、空气过滤器、出风口、回风口等组成。水系统由加湿水和排水系统组成。


第11章 IDC暖通末端加湿除湿一体化

11.1 加湿器工作原理
加湿器通过水泵将水箱内的水经由管路和淋水系统喷淋在湿膜上方，水在自然重力作用下将湿膜湿润，再由加湿机内部送风机将湿膜上的水份与干燥气流进行热交换，汽化成为高湿空气进行机房加湿。

11.2 除湿机工作原理
除湿机由风扇将潮湿空气抽入机内，经过制冷系统(压缩机、蒸发器、冷凝器)相互作用下凝结成霜，系统自动升温化霜成水流入盛水箱，产生干燥空气排出，如此循环使室内湿度降低。
